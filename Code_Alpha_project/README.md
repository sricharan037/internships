## Overview
During this internship, I worked on several assigned tasks to deepen my understanding of the Internet of Things, Artificial Intelligence integration, and sensor-based simulation. The tasks involved comprehensive research, case studies, and practical simulation using modern IoT tools.

## Projects & Tasks

### [Task 1: IoT Industrial Automation Report](./Task1_IoT_Industrial_Automation)
A detailed research report exploring the transformation of traditional manufacturing into smart factories through Industrial IoT (IIoT). The report covers smart sensors, predictive maintenance, IoT architecture, and real-world applications like Siemens and GE Predix.

### [Task 2: Sensor-Based Radar Simulation](./Task2_IoT_Radar_Simulation)
A practical IoT simulation developed on Wokwi. This project implements a real-time radar system using an Arduino Uno, an HC-SR04 ultrasonic sensor, a servo motor, and an OLED display to sweep and detect objects visually.

### [Task 4: IoT & AI Integration Case Study](./Task4_IoT_AI_Integration)
A comprehensive case study analyzing the synergy between IoT and Artificial Intelligence. It highlights how massive real-time data collection (IoT) combined with predictive analysis (AI) is revolutionizing industries such as healthcare, agriculture, and autonomous vehicles.
